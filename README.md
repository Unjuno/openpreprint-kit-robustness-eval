# OpenPreprint Kit robustness evaluation

**OpenPreprint Kitにおける改変検出・時刻証拠・障害復旧の実証評価** is an AI-assisted, unreviewed preprint by the author listed in `preprint.yaml`. It reports tamper-detection negative tests, offline restoration, timestamp verification, and publication failure analysis.

The owner authorized public publication of v1 and v2 on 2026-11-23. This does not mean the work has received independent peer review or audit. Authorship identity and scientific correctness are not independently verified. See [`docs/OWNER_PUBLICATION_APPROVAL.md`](docs/OWNER_PUBLICATION_APPROVAL.md), [`research-assets.yaml`](research-assets.yaml), and [`LICENSE-NOTICE.md`](LICENSE-NOTICE.md) for the publication decision and asset scope.

The current default branch identifies the latest manuscript version. Each released version is preserved separately in an immutable GitHub Release with its source commit and verification assets.
